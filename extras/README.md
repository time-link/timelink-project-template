# Extras

This directory receives auxiliary files of the project: working documents,
scripts, downloaded material and derived data that support the sources but are
not themselves Kleio sources, structures, mappings or inference rules.

Examples from existing projects: local documentation, data processing scripts,
geocoding working files, images downloaded from digital libraries, validation
data.

The `vscode/` subdirectory hosts the Kleio extension for VS Code, installed
with `code --install-extension extras/vscode/kleio-1.0.9.vsix`.
